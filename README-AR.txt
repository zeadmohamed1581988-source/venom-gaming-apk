VENOM GAMING APK - مشروع بناء التطبيق

هذا المشروع يجهّز تطبيق Android WebView يفتح مباشرة:
https://zeadmohamed1581988-source.github.io/venom-gaming/design.html

إضافة الألعاب وتعديل التصميم على GitHub Pages لا تتطلب إعادة بناء APK، طالما أن التطبيق ما زال يفتح نفس رابط الموقع.

بناء APK من GitHub (بدون Android Studio على الهاتف):
1) ارفع محتويات هذا المجلد إلى جذر مستودع venom-gaming على GitHub، مع الحفاظ على ملفات الموقع الموجودة.
2) افتح تبويب Actions في المستودع.
3) اختر Build VENOM GAMING APK.
4) اضغط Run workflow.
5) بعد انتهاء البناء افتح نتيجة التشغيل، ثم Artifacts، ونزّل VENOM-GAMING-APK.zip.
6) فك ضغطه وثبّت app-debug.apk على هاتف Android.

ملاحظات:
- التطبيق يحتاج الإنترنت لفتح الموقع أول مرة ولجلب أي محتوى غير محفوظ محليًا.
- تشغيل الألعاب دون إنترنت يعتمد على إعداد Service Worker وتخزين ملفات اللعبة داخل الموقع؛ التطبيق وحده لا يجعل كل لعبة أوفلاين تلقائيًا.
- هذه نسخة Debug للتجربة والتثبيت اليدوي، وليست إصدار متجر موقّعًا.
